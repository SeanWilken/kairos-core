# Kairos Core Charter

## Why this repo exists

Kairos Core exists to make private, practical AI setup easier for individuals and organizations.
The core output is not a single UI; it is a reliable backend runtime and contract surface that other tools can build on.

## What this repo is responsible for

- model access setup (local/BYO/API provider patterns)
- onboarding profile capture (goals, workstyle, strengths/weaknesses, milestones)
- knowledge ingestion and preparation (cleaning, review, retrieval readiness)
- policy-aware orchestration baseline
- auditable API contracts and event-oriented traceability

## What this repo is not responsible for

- forcing a single frontend/chat UX
- requiring one integration path
- requiring full model retraining in the MVP

## Product philosophy

- practical first, advanced later
- safe defaults over clever defaults
- composable architecture over monolithic lock-in
- contract stability over fast-breaking iteration

## MVP north star

Give users a safe way to run and use AI on their own systems or preferred providers, with their data ownership and security boundaries intact.
